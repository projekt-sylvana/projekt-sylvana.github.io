# PROJEKT SYLVANA – portfólió

Az erdőben, Hévíz és Keszthely között: előzmény, jelen és jövő, látványtervek, jelölt helyszínrajz, madártávlati képek, a telek határai, perspektívák, stílustanulmányok, böngészőben forgatható 3D modell, 360°-os túrák, adatok és nemzetközi kitekintés.

- `index.html` – a weboldal (egy fájl, a képek az `assets/img` mappában); angolul: `en.html`
- `modell.html` – a 3D modell nézegetője (three.js; a modell az `assets/3d` mappában, glTF/GLB); angolul: `modell-en.html`
- `Projekt_Sylvana_portfolio.pdf` – nyomtatható / küldhető változat (41 oldal, 1920 × 1080); angolul: `Projekt_Sylvana_portfolio_en.pdf`

Készült: Blender, D5 Render, Blender Cycles · 2026
